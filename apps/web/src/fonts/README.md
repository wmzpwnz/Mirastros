Cormorant Garamond variable font (wght 300–700), with Cyrillic and Latin glyphs.

Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
Source file: CormorantGaramond[wght].ttf
Stored as WOFF2 with fontTools; outlines and variable axes are unchanged.
License: SIL Open Font License 1.1, included in CormorantGaramond-OFL.txt.

Kept locally so display typography does not depend on a Google Fonts CSS response
at build time. Next.js emits the font as a versioned static asset.
