# Фоновые иллюстрации Mirastros

15 ноября 2026: оригинальные иллюстрации созданы image_gen по композиции
утверждённого владельцем макета «MIRASTROS — UI / UX DESIGN SYSTEM».
Иллюстрации не содержат встроенного интерфейса или надписей.

- `reference-landscape.png`: каменный портал слева, затмение, планета справа,
  спокойная центральная зона и низкий фиолетовый горизонт.
- `reference-mobile.png`: отдельная вертикальная композиция той же сцены.

WebP в `apps/web/public/images/mirastros-reference-*.webp` получены FFmpeg,
libwebp, quality 92, compression_level 6, без обрезки и изменения композиции.
PNG оставлены как исходники. Логотип и исходные анимации модулей не заменены.

Иллюстрация — художественная интерпретация эталона, не извлечение его пикселей.
