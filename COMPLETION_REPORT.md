# Mirastros: фактический статус

Предыдущие заявления о полностью завершённых OAuth, оплате и чате были
неподтверждёнными. Они заменены результатами проверки в
[RELEASE_READINESS](docs/RELEASE_READINESS.md).

Сборка и локальные тесты проходят. Публичная доступность, DNS/TLS, первый
релиз через GitHub Actions, реальные OAuth и платёжные sandbox-проверки
требуют отдельных подтверждений. Локальная LLM не используется; AI — DeepSeek API.
