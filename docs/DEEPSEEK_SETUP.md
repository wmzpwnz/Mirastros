# DeepSeek: серверное подключение

## Что работает без ключа

Короткое знакомство `/auth/onboarding` сохраняет имя, дату, город и время в общем
профиле. Значение имени берётся из справочника, число жизненного пути вычисляется
по правилам, положения небесных тел — Swiss Ephemeris. Итоговый портрет также
формируется без LLM. Эти шаги не ждут DeepSeek и не расходуют токены.

В backend уже есть единый `app/services/llm.py`, настройки `DEEPSEEK_API_KEY`,
`DEEPSEEK_API_URL`, `DEEPSEEK_MODEL`. Модель по умолчанию — `deepseek-chat`, адрес —
`https://api.deepseek.com/v1/chat/completions`. При пустом ключе, включая пробелы,
`generate` выдаёт `AIProviderUnavailable` до создания HTTP-клиента — как для
обычной выдачи, так и для потока. Ошибки провайдера не возвращают его сырой body.
Проверка доступности с неверным ключом не помечает модель загруженной.

## Когда потребуется ключ

Когда будем включать контекстное пояснение конкретного результата по кнопке
«Разъяснить», с доступом пробной/платной подписки и ограничениями использования.
Сейчас ключ не требуется. Автоматическая AI-генерация в короткое знакомство не
добавлена; существующий старый `/insight` не используется новым интерфейсом.
Наличие общего LLM-сервиса ещё не означает готовность тарификации всех старых
AI-модулей: перед их включением проверяем права, лимиты и историю отдельно.

## Как добавить позже

Ключ вводит владелец непосредственно на VPS в
`/srv/mirastros/shared/backend.env`. Это существующий закрытый файл окружения
backend; он не входит в архив релиза. В GitHub, чате и браузерной конфигурации
ключа быть не должно. Не использовать префикс `NEXT_PUBLIC_`.

При готовности функции:

1. Открыть файл через `sudoedit /srv/mirastros/shared/backend.env` на VPS.
2. Установить `DEEPSEEK_API_KEY` в реальное значение. Другие настройки и секреты
   оставить на месте; права файла не расширять.
3. Владелец перезапускает `mirastros-api` для чтения обновлённого окружения.
4. Выполняем один ограниченный запрос через утверждённый интерфейс с тестовым
   аккаунтом; проверяем пояснение, ограничение повторных запросов и учёт затрат.
   Значение ключа и содержимое файла в отчёт не копируем.

Вычисления остаются в алгоритмах модулей. В AI передаётся минимально необходимый
готовый результат, а не задача придумать положения планет или числовую матрицу.
Открытого бесконечного чата это подключение не создаёт.

## Проверки без секрета

`pytest -q test_llm_configuration.py test_welcome.py` проверяет отсутствие запросов
без ключа, модель/заголовки на имитации API, безопасную ошибку провайдера,
серверные расчёты и сохранение прогресса. Настоящий DeepSeek в этих тестах не вызывается.
