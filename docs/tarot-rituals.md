# Таро: тематические сеансы

`/services/tarot` использует `GET /tarot/rituals/catalog`, авторизованные `POST /tarot/rituals/reading`, `GET /tarot/rituals/reading/{id}` и `GET /tarot/rituals/history`.

15 раскладов, 7 категорий, позиции на 1/3/5 карт. Набор 78 карт (22 старших, по 14 в каждой из четырёх мастей), нумерация соответствует существующему app/data/tarot.py. Значения на русском — редакционные символические пояснения, не прогнозы событий или сведения о третьих лицах. Командные темы предназначены только для добровольной рефлексии, не оценки кандидатов.

Сервер перемешивает колоду SystemRandom, выбирает разные карты по выбранным индексам, сохраняет значения и положения до ответа. Идентификатор запроса обеспечивает повтор без нового расклада. Все чтения проверяют владельца. Блокировка аккаунта сериализует создание; карта дня повторно возвращается в пределах календарного дня часового пояса профиля (UTC при некорректном поясе). Не более 30 новых базовых сеансов за скользящие сутки. Базовый результат не требует ИИ. ClarifyButton обращается к существующему серверному контролю подписки/пробных кредитов, стоимости и одного уточнения.

Сохранения используют TarotReading и совместимы с общей историей и пояснениями. URL содержит только UUID результата; чужому аккаунту он не даёт доступа. История отображает последние 30 тематических сеансов.

## Иллюстрации

Единый каталог: apps/backend/app/data/tarot_rituals.json. Поля deck.back и cards[].image пока null: интерфейс показывает оформленную символическую карту. Не выдавать её за пользовательскую иллюстрацию.

Загруженные пользователем изображения разместить в apps/web/public/images/tarot/mirastros-78/. В каталоге прописать `/images/tarot/mirastros-78/back.webp` и пути лиц по неизменным id 0..77. Сопоставлять по имени, не по случайному порядку файлов. Не менять id и не перезаписывать смыслы сохранённых раскладов. CSS использует object-fit:contain; при ошибке изображения остаётся читаемая символическая карта. Изображения не являются ключами расчёта.

Обновлённые изображения должны использоваться также для старых сеансов по id из текущего каталога. Поворот перевёрнутой карты применяется к лицу, подписи остаются читаемыми. Анимация переворота отключается при prefers-reduced-motion.
