# Matrix reading experience

The production /destiny-matrix view uses the existing authenticated atlas API and unchanged reference calculations. Saved results remain compatible.

The presentation provides an introduction, nine interactive plotted positions with labels, explanations for all nineteen supported positions, and a ten-step guided reading. Each reading includes position meaning, an original symbolic energy theme, a contextual opportunity, a limitation, a question, and a practice. Calculations are collapsed by default but remain inspectable and downloadable.

Texts in matrixReading.ts are original Mirastros reflection prompts. They are not quotations, certified Ladini interpretations, scientific personality assessments, diagnoses, or forecasts. The 22 editorial theme names are not presented as the original school's energy names. Do not add money, health, age or relationship calculations without a separately documented verified method.

Visual identity follows the matrix portal: silver/lavender, dark indigo, fine geometric lines, softly illuminated nodes and framed panels. Mobile uses a vertical layout and brings the selected explanation into view. Reduced motion is respected. All nodes and guide controls are keyboard-operable.
