# Mirastros Design System

Welcome to the Mirastros Design System Storybook. This is an interactive component library and documentation hub for the unified design system across all Mirastros applications.

## Overview

The Mirastros Design System provides:

- **40+ Reusable Components** - Pre-built UI components for consistent interfaces
- **Design Tokens** - Centralized colors, typography, spacing, and animations
- **Accessibility** - WCAG 2.1 AA compliant components
- **Responsive Design** - Mobile-first approach with breakpoints for all screen sizes
- **Dark & Light Themes** - Full theme support with CSS variables
- **Documentation** - Comprehensive guides and best practices

## Getting Started

### Installation

```bash
npm install @mirastros-universal/design-system
```

### Basic Usage

```tsx
import { Button, Card } from '@mirastros-universal/design-system';

export function App() {
  return (
    <Card>
      <h1>Welcome</h1>
      <Button variant="primary">Click Me</Button>
    </Card>
  );
}
```

## Design Principles

### Cosmic Aesthetic
The design system embraces a cosmic theme with:
- Dark background (#050505)
- Gold accents (#FFC107)
- Turquoise secondary accents (#00BCD4)
- Elegant typography with Cinzel headings

### Accessibility First
All components are built with accessibility in mind:
- Keyboard navigation support
- Screen reader friendly
- WCAG 2.1 AA contrast compliance
- Semantic HTML

### Performance Optimized
- GPU-accelerated animations
- Minimal bundle size
- Efficient re-renders
- Responsive images
